# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Use GitHub **Private vulnerability reporting** to disclose issues confidentially:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Include a description, reproduction steps, and affected versions.

We will respond, coordinate a fix, and agree on a disclosure timeline with you.

Thank you for helping keep this project and its users safe.
